# 🌸 AnimeVerse

AnimeVerse is a modern anime tracking website built with **HTML**, **CSS**, and **JavaScript**.  
It lets users explore trending anime, view top-rated shows, manage their personal watch list, and track viewing statistics — all in one stylish interface.

---

## 🚀 Features
- 🎨 Responsive design with gradient theme and smooth animations  
- 🔥 Trending and Top Rated anime sections (50+ anime cards)  
- 🧩 Genre filters and search functionality  
- 🕹️ Interactive Watch List system  
- 📊 Dashboard with viewing statistics  
- 🌙 Dark Mode toggle  
- 💻 Built using pure HTML, CSS, and JavaScript  

---

## 🧠 Technologies Used
| Component | Description |
|------------|-------------|
| **HTML5** | Structure and layout |
| **CSS3** | Styling, animations, and responsive design |
| **JavaScript** | Dynamic features (dark mode, watch list, future API integration) |
| **Font Awesome** | Icons for navigation and buttons |
| **Google Fonts (Poppins)** | Clean and modern typography |
